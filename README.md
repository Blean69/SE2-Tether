# SE2-MP (working name)

An **unofficial, fully open-source multiplayer plugin for Space Engineers 2**, for Windows and Linux.

**Status: planning.** There is no code yet. Start with the design plan in
[`docs/PLAN.md`](docs/PLAN.md). The research behind it is in
[`docs/research/2026-11-landscape.md`](docs/research/2026-11-landscape.md).

## Principles

- **All source is public**, under an OSI-approved license (to be decided).
- Builds are reproducible, so anyone can check that a download matches the code.
- No account gates and no telemetry.
- No closed executables. Install scripts are short and readable.
- Windows and Linux are equals:
  - Windows;
  - Linux via Proton;
  - native Linux via Pulsar and LinuxCompat;
  - Linux dedicated servers.
- We never redistribute Keen Software House files.
